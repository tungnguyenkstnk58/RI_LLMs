# Divergence-Based Safety Measure for Large Language Models

This repository contains Jupyter Notebook code for the experiments in the paper:

**Divergence-based Safety Measure for Large Language Models via Rational Inattention**

This notebook compares GPT-2 and GPT-Neo-125M under the proposed divergence-based safety measure. It uses the same prompts, candidate-adjective pool, embedding-attack budget, and trust tolerance for both models.
