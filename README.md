# RI_LLMs

# Bounded Rationality and Safety Metrics for LLMs

This repository contains MATLAB code for the experiments in the paper:

**Toward Understanding Bounded Rationality and Safety in Large Language Models via Rational Inattention Framework**

The code implements a small word-level multi-head attention benchmark trained on a templated English corpus. The goal is not to benchmark large-scale language-model performance, but to illustrate how the proposed bounded-rationality and safety metrics can be computed in practice.

## How to Run the Simulation

The simulation has two main steps:

1. train the small multi-head attention benchmark;
2. evaluate the bounded-rationality and safety metrics using the trained model.

Please run the scripts from the same folder, since the evaluation script loads the `.mat` file generated by the training script.

### Step 1: Run training_multihead_templated_english.m

### Step 2: Run performance_metrics_evaluation
